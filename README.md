# Histórias de Usuário - Sistema de Aluguel de Carros.

## Cliente
- *Como cliente, quero me cadastrar no sistema, para que eu possa acessar e utilizar os serviços de aluguel.
- *Como cliente, quero fazer login no sistema, para que eu possa acessar minhas informações e gerenciar meus pedidos.
- *Como cliente, quero realizar um pedido de aluguel, para que eu possa alugar um carro conforme minha necessidade.
- *Como cliente, quero cancelar um pedido de aluguel, para que eu possa desistir do aluguel antes da aprovação.
- *Como cliente, quero consultar o status do meu pedido, para que eu possa acompanhar sua aprovação ou rejeição.
## Agente
- *Como agente, quero avaliar pedidos de aluguel, para que eu possa verificar a viabilidade financeira dos clientes.
- *Como agente, quero aprovar ou rejeitar pedidos, para que eu possa garantir que apenas clientes aptos aluguem um carro.

## Sistema
- *Como sistema, quero armazenar os dados dos automóveis disponíveis, para que os clientes possam visualizar e escolher um carro.
- *Como sistema, quero associar contratos aos pedidos aprovados, para que o aluguel esteja formalizado e registrado.
